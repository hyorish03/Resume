  • 판단:라이브러리 하나가 아니라 화면 전용 의존성이 공통 경로로 새는 구조가 원인이라고 보고 eager 경로와 프로덕션에 섞인 mock을 분리했고, 입력 지연은 키마다 돌던 SQL 포매터를 화면에 보일 때만 실행하도록 바꿨습니다.
